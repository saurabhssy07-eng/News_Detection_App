    ⚙️ How It Works

  • 1. Input: Text, URL, or PDF upload (drag & drop supported)
  • 2. Extraction: BeautifulSoup parses HTML, PyMuPDF handles PDFs
  • 3. Analysis: DistilBERT for classification + RoBERTa for sentiment
  • 4. Scoring: Ensemble model with confidence thresholds
  • 5. Results: Real-time probabilities + explanations

    • Powered by FastAPI backend with hybrid ML/NLP pipeline. Processing time: <5 seconds average.
